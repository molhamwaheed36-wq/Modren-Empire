# Modren Empire UI Design

The Android-first interface uses a premium dark technology-management visual language.

- Persistent left navigation for major management systems.
- Top KPI bar for cash, debt, company level, and reputation.
- Card-based dashboards for readable touch targets.
- Accent hierarchy: cyan for technology, green for positive/economic systems, gold for director/major actions, red for risk/debt/competition.
- Scrollable content for phones and small displays.
- 42px minimum primary action targets to support touch interaction.
- Dashboard, Company, Product Lab, R&D, Factory, Supply Chain, Staff, Markets, Competitors, Finance, Bank, Events, Game Director, LAN, and Settings are exposed as first-class sections.
- The interface is generated in GDScript so it can be restyled without replacing the simulation layer.
